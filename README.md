# Frozen Jackpot

Lightweight HTML5 slot machine called "Frozen Jackpot".

- Modular architecture with ES modules in js/
- CSS separated in css/style.css
- localStorage save/load using js/storage.js
- Frozen HOLD mechanic: press HOLD buttons to freeze reels across spins
- Slot machine animation via js/reel.js
- Sound effects using WebAudio in js/sound.js (no external files)
- Mobile responsive

Open index.html in a browser. Files are static.
